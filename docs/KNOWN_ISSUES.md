# Known Issues

## Objetivo

Este documento regista limitações, problemas conhecidos e comportamentos inesperados encontrados durante o desenvolvimento.

O objetivo é evitar interromper um Sprint para resolver problemas secundários.

Sempre que um problema não bloquear o Sprint atual, deve ser registado aqui e resolvido posteriormente.

---

# Estado Atual

De momento não existem problemas conhecidos.

---

# Formato

Cada novo problema deve seguir o seguinte formato.

## [Data]

### Título

Descrição do problema.

### Impacto

Baixo / Médio / Elevado

### Estado

Aberto

Em análise

Resolvido

### Sprint

Sprint onde foi identificado.

### Observações

Informação adicional.

---

# Regras

Não utilizar este documento para:

- ideias;
- melhorias;
- novas funcionalidades.

Este documento destina-se apenas a problemas técnicos ou limitações conhecidas.
