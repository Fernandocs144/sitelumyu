# Lumyo Experience Engine

## Objetivo

O website da Lumyo não é um website tradicional.

Não foi concebido para apresentar serviços.

Foi concebido para demonstrar aquilo que a Lumyo é capaz de construir.

O visitante deve sentir que entrou numa experiência digital de nova geração.

No final da visita deve pensar:

> "Se a própria Lumyo construiu um website assim, imagino o que conseguem desenvolver para a minha empresa."

Todo o desenvolvimento deste projeto deve servir este objetivo.

---

# Filosofia

A homepage é uma única experiência contínua.

Não existem secções independentes.

Não existem animações isoladas.

Existe apenas uma entidade digital que evolui ao longo do scroll.

Tudo o que o utilizador vê pertence à mesma matéria.

Essa matéria muda apenas de forma.

Nunca desaparece.

Nunca é substituída.

Nunca faz fade para outro elemento.

Tudo evolui naturalmente.

---

# Narrativa

A experiência segue obrigatoriamente esta sequência.

Robot

↓

O robot começa a dissolver-se.

↓

As partículas transformam-se numa fibra digital.

↓

Essa fibra percorre toda a homepage.

↓

A fibra constrói cada elemento da interface.

↓

Quando termina uma secção, a fibra dissolve novamente esse elemento.

↓

A mesma fibra continua viagem.

↓

Mais à frente reorganiza-se.

↓

Forma o "L" da Lumyo.

↓

O "L" estabiliza.

↓

Cristaliza.

↓

Transforma-se no diamante Lumyo.

↓

O diamante acumula energia.

↓

Explode.

↓

As partículas entram em órbita.

↓

Forma-se a galáxia final.

Toda a homepage conta esta história.

---

# A Fibra Digital

A fibra digital é o elemento principal da identidade visual.

Não é apenas uma linha.

Não é um efeito.

É uma entidade viva.

Visualmente deve lembrar:

- fibras óticas
- energia
- partículas
- luz
- dados
- fluxo digital

A fibra nunca permanece totalmente estática.

Está constantemente viva.

Respira.

Oscila.

Transporta energia.

---

# Construção dos elementos

Nenhum elemento importante deve aparecer instantaneamente.

Tudo deve ser construído pela fibra.

Exemplos:

Cartões.

Logótipos.

Símbolos.

Diamante.

Qualquer objeto importante.

O utilizador deve conseguir perceber que todos esses elementos nasceram da mesma matéria.

---

# Destruição dos elementos

Nenhum elemento desaparece através de fade.

Nenhum elemento desaparece instantaneamente.

Quando um elemento deixa de existir:

- dissolve-se
- regressa à fibra
- continua viagem

A matéria nunca desaparece.

Apenas muda de forma.

---

# Scroll

O scroll controla a narrativa.

Cada posição do scroll representa um estado da experiência.

Não existem saltos.

Não existem mudanças abruptas.

O utilizador sente que controla a transformação da matéria.

---

# Objetivo emocional

O utilizador deve sentir:

Curiosidade.

Elegância.

Tecnologia.

Precisão.

Inovação.

Exclusividade.

Nunca excesso.

Nunca caos.

Nunca distração.

---

# Performance

Toda a experiência deve privilegiar:

- 60 FPS
- animações suaves
- transições contínuas
- carregamento rápido
- otimização para desktop e mobile

O aspeto visual nunca deve comprometer a fluidez.

---

# Regras Absolutas

Nunca utilizar:

- fades entre secções
- elementos que aparecem do nada
- transições bruscas
- animações sem ligação à narrativa
- componentes visuais independentes da fibra

Tudo deve nascer da mesma entidade.

Tudo deve regressar à mesma entidade.

---

# Arquitetura

O código deve ser modular.

Cada sistema deve ter apenas uma responsabilidade.

Exemplos:

Experience Engine

↓

Scroll Controller

↓

State Machine

↓

Particle System

↓

Fiber System

↓

Morph System

↓

Robot System

↓

Logo System

↓

Diamond System

↓

Galaxy System

↓

Render Pipeline

Nenhum ficheiro deve concentrar toda a lógica da experiência.

# Objetivo Final

O visitante não deve sentir que navegou por um website.

Deve sentir que assistiu a uma transformação digital contínua.

Essa transformação representa exatamente aquilo que a Lumyo entrega aos seus clientes.

Não vendemos websites.

Não vendemos automações.

Não vendemos inteligência artificial.

Vendemos transformação digital.
